# Soford ERP 产品需求文档（PRD）

版本：v1.0　日期：2026-09-29

## 1. 背景与目标

Soford 在 Alibaba.com 国际站（ICBU）经营 B2B 商品。目前商品资料散落在 Excel 中，上架依赖人工在卖家后台逐个录入，效率低、易出错、无法追踪。

**目标：** 提供一个内部 ERP 工作台，让运营人员可以
**「导入/录入商品 → 质检 → 类目与属性补全 → 一键发布到 Alibaba → 回写上架状态 → 后续同步价格库存」**，整个流程在一个系统内闭环完成，每一步可追踪、可重试。

### 现状问题（v0 不可用的根因）

| # | 问题 | 影响 |
|---|------|------|
| 1 | 网关地址配置为 `openapi.alibaba.com/rest`，实际应为 `openapi-api.alibaba.com/rest` | 所有接口 404 |
| 2 | 签名用的是旧淘宝 TOP 协议（MD5 + 北京时间），ICBU 新平台要求 IOP 协议（HMAC-SHA256 + API 路径前缀 + 毫秒时间戳） | 所有接口 `IncompleteSignature` |
| 3 | Token 参数名用 `session`，应为 `access_token` | 授权接口全部 `IllegalAccessToken` |
| 4 | Alibaba 错误以 HTTP 200 返回，系统只看 HTTP 状态码 | 失败被误判为成功 |
| 5 | 发布报文是自定义扁平结构，不符合 `product_info` 规范 | 发布必然失败 |
| 6 | 本地运行不读取 `.env`，AppKey 为空 | 授权按钮置灰，所有功能被禁用 |
| 7 | 远端商品 ID 不回写，后续同步用 SKU 代替 | 状态/库存/价格同步不可用 |
| 8 | 导入列名匹配、空 SKU 覆盖、状态被质检覆盖等数据 bug | 数据错误 |

## 2. 用户与角色

| 角色 | 说明 |
|------|------|
| 管理员/运营 | 唯一角色（v1）。负责授权店铺、维护商品、发布与同步。 |

v1 为单管理员账号（配置文件设定）。多用户/权限不在本期范围。

## 3. 核心业务闭环

```
 ①连接检查 → ②店铺授权 → ③商品入库(导入/新建) → ④质检
      → ⑤类目预测 + 类目属性补全 → ⑥图片上传图片银行
      → ⑦发布(新建/更新) → ⑧状态回写(审核中/已上架/失败原因)
      → ⑨价格/库存同步、上下架 → ⑩任务与日志审计
```

## 4. 功能需求

### F1 登录
- 用户名/密码登录，会话 Cookie，最长 24 小时；会话过期自动回到登录页。
- 连续 5 次失败锁定 5 分钟（防暴力破解）。

### F2 连接与授权（「店铺连接」页）
- **连接自检**：一键检查并逐项显示 ✅/❌ 与修复建议：
  AppKey/AppSecret 是否配置、网关是否可达、签名是否被 Alibaba 接受、Token 是否存在/过期、回调地址、数据目录是否可写。
- **一键授权**：跳转 Alibaba 授权页，回调后自动换取 Token。
- **手动授权**：粘贴回调 URL 或 code 即可换取 Token（用于本地环境，回调地址指向生产域名时）。
- **自动续期**：Token 过期前 5 分钟自动刷新；刷新失败提示重新授权。
- 显示授权账号、Token 过期时间。

### F3 商品管理（「商品」页）
- 列表：图片、标题/SKU、类目、价格、起订量、库存、本地状态、远端状态、质检结果。
- 搜索（SKU/标题/类目/远端ID）、按状态筛选、分页（每页 20/50/100）。
- 新建/编辑：分区表单（基础信息 / 类目与属性 / 价格与库存 / 物流 / 图片）。
- 删除需二次确认；支持批量删除。
- 字段（对齐 Alibaba `product_info`）：
  - 基础：SKU*、英文标题*、描述*、关键词、品牌、型号、语言(默认 en_US)
  - 类目：类目ID、类目名称/路径、类目属性（名称-值列表）
  - 交易：币种、价格(单价或阶梯价)、起订量*、单位(默认 Piece)、库存
  - 物流：交期(天)、运费模板ID、重量(kg)、包装尺寸(cm)
  - 图片：最多 6 张，第一张为主图
  - 远端：Alibaba 商品ID、远端状态、失败原因、最后同步时间（只读）
- SKU 唯一；重复时提示，不允许静默覆盖。

### F4 导入
- 支持 `.xlsx`、`.csv`（UTF-8，支持引号内换行）。
- 表头支持中英文别名、忽略大小写/空格/下划线。
- 按 SKU 匹配：存在则更新（保留远端ID与发布状态），不存在则新建。
- 返回导入报告：新增 N、更新 N、跳过 N、逐行警告（数字无法解析等）。
- 下载 xlsx 模板（含表头说明与示例行）。

### F5 质检
- 本地规则：必填项、标题长度 ≤128、价格>0 且最多两位小数、起订量>0、库存≥0、图片为 http(s) 且 ≤6 张、关键词≥3（警告）、属性≥3（警告）。
- 类目规则：若已拉取类目属性，校验「必填属性」是否填写（阻断）。
- 分级：阻断 / 警告 / 提示。有阻断项的商品不可发布。
- 质检只影响「待完善/可发布」，不覆盖「已上架/审核中/失败」等远端状态。

### F6 类目与属性
- 类目预测：按标题/描述/主图调用 Alibaba 预测，回填类目ID、名称、路径（可批量）。
- 类目属性：拉取该类目属性（缓存 24h），编辑页中列出，标注必填、提供可选值下拉，支持自定义值。

### F7 图片
- 在编辑页上传本地图片到 Alibaba 图片银行，成功后自动加入商品图片列表。

### F8 发布
- 单个或批量发布；未上架过的走「新建」，已有远端ID的走「更新」。
- 发布前自动质检，阻断项直接拦截并显示原因。
- 后台任务执行，页面显示进度（总数/成功/失败），可离开页面稍后查看。
- 成功：回写远端商品ID，状态「审核中」；随后自动查询一次上架状态。
- 失败：状态「发布失败」，显示 Alibaba 错误码与中文说明。
- 可选开启 Alibaba AI 优化（标题/描述/关键词）。
- API 未配置/未授权时：不发请求，提示原因，并提供 CSV 导出兜底。

### F9 同步与上下架
- 查询上架状态（online/pending/draft/failed → 已上架/审核中/草稿/失败 + 原因）。
- 同步库存、同步价格（使用远端商品ID）。
- 上架 / 下架（批量）。
- 未发布（无远端ID）的商品，这些按钮不可用并提示原因。

### F10 任务与日志
- 发布任务列表：时间、类型、商品数、进度、结果，可展开查看每个商品的结果。
- API 日志：时间、接口、耗时、成功/失败、错误码、request_id；可查看脱敏后的请求参数与响应摘要。

### F11 API 调试台（高级）
- 选择已登记接口，填写 JSON 参数直接调用，查看原始响应。用于排障。

## 5. 非功能需求

| 项 | 要求 |
|----|------|
| 可用性 | 本地一条命令启动；服务器按文档部署；缺配置时启动不崩溃并在界面给出指引（生产环境缺管理员密码除外） |
| 数据安全 | 数据文件原子写入，崩溃不损坏；Token 加密存储；日志中 access_token/sign 脱敏 |
| 性能 | 1000 个商品列表响应 < 1s；批量发布不阻塞 HTTP 请求 |
| 可靠性 | Alibaba 调用超时 30s；网络异常记录日志并返回明确错误；Token 刷新串行化 |
| 可维护性 | 后端按领域拆分文件；前端按页面拆分组件；核心逻辑有单元测试 |
| 界面语言 | 中文 |

## 6. 不在本期范围

订单、物流发货、多 SKU 变体、多店铺、多用户/权限、从 Alibaba 反向拉取商品库。接口层已预留，后续迭代。

## 7. 验收标准

1. `start-local.ps1` 启动后登录，「店铺连接」自检中配置/网关/签名三项全部 ✅。
2. 粘贴有效授权 code 后 Token 显示已保存及过期时间。
3. 下载模板 → 填写 → 导入，报告正确，交期等所有列都能读入。
4. 质检能正确给出阻断/警告，发布被阻断商品时给出原因。
5. 类目预测能回填类目；类目属性能在编辑页展示并校验必填。
6. 发布成功后商品显示 Alibaba 商品ID和「审核中/已上架」；失败显示 Alibaba 错误信息。
7. 对已发布商品执行同步库存/价格/状态、上下架，结果正确显示。
8. 所有调用在 API 日志中可查，敏感字段已脱敏。
9. 后端单元测试全部通过，前端 `npm run build`、`npm run lint` 通过。
