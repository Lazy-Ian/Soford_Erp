### 代码审查记录（2026-09-29）

**第一轮**：无严重问题，高 4 个、中 9 个、低 3 个，已全部修复并补充回归测试。

| 级别 | 问题 | 修复 |
|------|------|------|
| 高 | 只含部分列的表格导入时会清空其他字段 | 只更新表中存在的列；模板说明补充部分更新的用法 |
| 高 | 创建超时后重试可能在 Alibaba 生成重复商品 | 发布接口超时放宽到 120s；始终发送型号；超时后按型号查回商品，不直接判为失败 |
| 高 | 状态轮询、发布、导入并发时会互相覆盖结果 | 按商品加锁，同一商品的操作串行执行；导入跳过快照之后发生的变化；新增「有未发布的修改」标记 |
| 高 | 单个商品出错会中断整批任务，商品卡在「发布中」 | 每个商品单独捕获异常并恢复状态；ID 解析失败时给出明确提示 |
| 中 | 旧版数字状态映射错误、后台同步异常导致进程退出、重复属性名/超大数字/空 productIds 导致 500、备份与运行中的写入冲突、Docker 端口暴露、进度条卡住、上传图片覆盖编辑 | 逐项修复 |
| 低 | 证书提示错误、审核中计数口径不一致、导出选中过多时 URL 过长 | 改提示、统一口径、导出改用 POST |

### 第三期（上线评估与优化，2026-09-29）

按真实数据（1238 个商品、7 个账号，其中 2 个已授权）做了一轮上线评估。结论：代码可以上线，但必须先完成 ICP 备案（见下方「上线前必须由人完成」）。

| 阶段 | 问题 | 修复 | 验证 |
|------|------|------|------|
| M13 | 商品列表接口每次返回 28 MB（其中 25 MB 是导入的 Alibaba 详情 HTML），小带宽服务器上打开一次要一分钟左右；发布时每处理一个商品就重新加载一次 | 列表不带描述，编辑器按 ID 加载完整商品；任务结束时才重新加载；nginx 开启 gzip | 列表 2.7 MB（压缩前），编辑器拿到完整描述 |
| M14 | 每次读写都要重新解析 36 MB 的 products.json（单次约 0.15–0.4 s） | 仓储改为内存缓存 + 原子写盘；写入失败时丢弃缓存；API 日志同样缓存 | 缓存后列表约 24 ms；新增缓存隔离、写入持久化、失败回滚测试 |
| M15 | 同步状态/库存/价格、上下架、预测类目在 HTTP 请求里逐个执行，几百个商品会超过 nginx 超时（504），而服务器还在继续改线上数据 | 统一改为后台任务（与发布同一个队列），上下架每 20 个一批；「发布任务」页改为「后台任务」；任务进度每 2 秒保存一次 | 真实网关跑通状态同步任务 |
| M16 | 状态接口 `status/get/v2` 对卖家后台创建的商品一律返回 `{"type":"ISP","message":"Product not found."}`，却被当成成功，状态被写成「未知状态」 | 带 `type` 且没有 `code` 的响应按失败处理；状态查询失败时改用 `product.get` 的 status + audit_status；导入时审核被拒的商品标为「审核未通过」 | 真实网关：3 个商品正确显示已上架/已下架 |
| M17 | 发布时选了操作账号，会把已由其他账号负责的商品永久改归该账号，之后更新/同步会因权限失败 | 只有未发布的新商品归到所选账号 | 代码审查 |
| M18 | 后台自动同步只看默认账号；遇到一个授权错误就整轮停止；持续失败的商品永远排在最前面 | 任一账号已授权即运行；只跳过出问题的账号；按最近尝试时间排队 | 单元测试 |
| M19 | 数据安全：密钥丢失时账号文件会被空列表覆盖；0 字节数据文件被当作「没有数据」，下次写入会清空全部商品；写盘未强制落盘 | 无法解密的账号文件改名保留；空数据文件报错并拒绝写入；写盘 `Flush(true)` 后再替换 | 新增 2 个测试 |
| M20 | 安全：API 调试台可调用删除商品、换取 Token 等接口；转发头信任任意来源 | 生产环境调试台只允许只读接口；只信任本机和内网代理 | 代码审查 |
| M21 | 前端：输入法按 Esc 会关闭编辑框；误点遮罩丢失修改；会话过期时整页换成登录页，编辑内容丢失；同步库存/价格/预测类目无确认 | 忽略输入法中的 Esc；有未保存修改时先确认；登录过期改为浮层登录，当前页面保留；三项操作加确认 | 浏览器实测 |
| M22 | 部署：升级中途失败会让服务停着；index.html 被缓存导致升级后白屏；缺少安全响应头 | 失败自动回滚到上一版并启动；index.html 不缓存；补充安全头；代理超时 300 s；「从 Alibaba 导入」不再因页面关闭而中断 | `bash -n`；nginx 配置未能在本机实测（Docker 未运行），首次部署时以 `nginx -t` 为准 |

最终：后端单元测试 69/69 通过，Release 构建 0 警告，前端 build 与 lint 通过。
