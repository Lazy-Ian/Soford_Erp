### 代码审查记录（2026-09-29）

**第一轮**：无严重问题，高 4 个、中 9 个、低 3 个，已全部修复并补充回归测试。

| 级别 | 问题 | 修复 |
|------|------|------|
| 高 | 只含部分列的表格导入时会清空其他字段 | 只更新表中存在的列；模板说明补充部分更新的用法 |
| 高 | 创建超时后重试可能在 Alibaba 生成重复商品 | 发布接口超时放宽到 120s；始终发送型号；超时后按型号查回商品，不直接判为失败 |
| 高 | 状态轮询、发布、导入并发时会互相覆盖结果 | 按商品加锁，同一商品的操作串行执行；导入跳过快照之后发生的变化；新增「有未发布的修改」标记 |
| 高 | 单个商品出错会中断整批任务，商品卡在「发布中」 | 每个商品单独捕获异常并恢复状态；ID 解析失败时给出明确提示 |
| 中 | 旧版数字状态映射错误、后台同步异常导致进程退出、重复属性名/超大数字/空 productIds 导致 500、备份与运行中的写入冲突、Docker 端口暴露、进度条卡住、上传图片覆盖编辑 | 逐项修复 |
| 低 | 证书提示错误、审核中计数口径不一致、导出选中过多时 URL 过长 | 改提示、统一口径、导出改用 POST |

**第二轮**（复查修复本身）：确认上述修复正确、无死锁；另发现 6 个问题，已修复。

| 级别 | 问题 | 修复 |
|------|------|------|
| 高 | 查重可能把另一个同型号商品的 Alibaba 商品当成自己的并覆盖 | 只在本商品有未确认的创建记录时才查重；排除已关联其他本地商品的 ID；只接受创建时间之后的唯一候选；拉取时有歧义不关联 |
| 中 | 内容没变的导入也会标记「有未发布的修改」 | 按内容比较，确实变化时才标记 |
| 中 | 旧服务器使用短密码，升级后 API 无法启动 | 安装脚本按与 API 相同的规则提前检查并提示 |
| 低 | 备份失败时服务停着没启动；发布成功后查询状态出错会被误回滚；部分导入时类目名称/阶梯价残留旧值 | 逐项修复 |

最终：后端单元测试 52/52 通过，Release 构建 0 警告，前端 build 与 lint 通过，模拟网关端到端复测通过。

## 风险与依赖

| 风险 | 应对 |
|------|------|
| 真实发布需要卖家授权 code 和 App 已开通的接口权限 | 自检页明确提示；无权限时 Alibaba 返回的错误码原样展示；CSV 兜底 |
| 回调地址登记为生产域名，本地无法自动回调 | 提供「粘贴回调 URL」手动授权 |
| Alibaba 对部分类目有额外必填属性 | 拉取类目属性并在质检中校验必填 |

## 验收记录（2026-09-29）

验证环境：
- **真实网关**：`https://openapi-api.alibaba.com/rest` + `.env` 中的 AppKey/AppSecret。
- **模拟网关**：本地 mock。严格校验 HMAC-SHA256 签名和毫秒时间戳，multipart 文件字段要求 filename 带引号，按官方文档的响应结构返回成功和业务错误。用于验证需要卖家 Token 的流程。

| # | 验收项（PRD §7） | 结果 | 说明 |
|---|------------------|------|------|
| 1 | 自检：配置/网关/签名全部通过 | ✅ 真实网关 | 签名被 Alibaba 接受（假 code 返回 `InvalidCode`） |
| 2 | 粘贴 code 换取 Token | ✅ 模拟网关 / ✅ 真实网关（错误路径） | 支持整段回调 URL；无效 code 给出中文提示 |
| 3 | 模板下载 → 导入 | ✅ | 中英文表头、GBK/UTF-8、引号内换行、阶梯价、交期均正确读入 |
| 4 | 质检阻断/警告，发布时拦截 | ✅ | 阻断商品在发布结果中列出全部原因 |
| 5 | 类目预测回填；类目属性展示并校验必填 | ✅ 模拟网关 | 必填属性自动加入并标红，未填时阻断发布 |
| 6 | 发布成功回写商品 ID 与状态；失败显示错误 | ✅ 模拟网关 | 后台任务 + 进度条；业务错误码附中文说明；再次发布走 update |
| 7 | 同步状态/库存/价格、上下架 | ✅ 模拟网关 | 审核中 → 已上架 → 已下架 → 更新后已上架 |
| 8 | API 日志可查且脱敏 | ✅ | access_token / sign / code 显示为 `***`，Token 响应不落日志 |
| 9 | 单元测试、build、lint | ✅ | `dotnet test` 28/28；`npm run build`、`npm run lint` 通过 |

### 待用户完成（需要卖家账号，无法代为操作）

1. 用卖家账号完成一次真实授权（「店铺连接」→ 授权 → 粘贴回调链接）。
2. 在「店铺连接」重新自检，确认「接口权限」为通过；如提示无权限，到 App Console 申请商品发布相关 API 权限包。
3. 选 1 个商品真实发布，确认 Alibaba 后台出现该商品。如果 Alibaba 对某些字段有额外要求，会以错误码形式显示在结果和 API 日志中。
